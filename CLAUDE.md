# CLAUDE.md - neuraldiff-docs

## What This Repo Is

Public documentation for NeuralDiff. This repo should explain the product, setup, public interfaces, and safe contribution guidelines.

## What Should Stay Public

- product overviews
- getting started guides
- public API and tool references
- customer-safe troubleshooting docs
- educational explanations of common visual regression problems

## What Must Stay Out Of This Repo

- proprietary algorithm details
- confidence models, thresholds, or calibration rules
- benchmark internals and research datasets
- patent or grant strategy materials
- internal AI-agent playbooks

## Internal Home

Internal agent and algorithm docs should live in the daemon/api project under private internal docs, not here.
